# Contributing to Enterprise MLOps Pipeline

We welcome contributions to improve our pipeline structure, serving API, or monitoring configurations.

## Development Setup

1. Fork and clone the repository.
2. Install Python 3.10 and set up a virtual environment.
3. Install development requirements:
   ```bash
   pip install -r requirements.txt
   pip install pytest flake8 black
   ```

## Branch Strategy

- Implement updates in feature branches created from the main branch.
- Naming format: `feature/your-feature-details` or `fix/issue-remediation`.

## Commit & PR Conventions

- Commit descriptions should explain the change clearly.
- Ensure all automated checks (linting, tests) pass before requesting code reviews.
