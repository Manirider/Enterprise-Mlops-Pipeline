# Security Policy

## Supported Versions

Only the latest version on the main branch receives security updates.

## Vulnerability Reporting

Please report security issues directly to manikantasuryasai21295cm055@gmail.com. Do not create public issues for vulnerabilities.

## Best Practices

- Secure MLflow UI access using network firewalls or basic authentication wrappers.
- Do not commit environment variables containing storage bucket credentials or access keys to version control.
